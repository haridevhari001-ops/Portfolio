# Haridev Portfolio

A responsive personal developer portfolio built with React, Vite, Tailwind CSS v4, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Before publishing

1. In `src/App.jsx`, replace `your-email@example.com` with your real email address.
2. Put your resume PDF in `public/Haridev-Resume.pdf` (create the `public` folder if needed).
3. Replace each project `github: "#"` and `demo: "#"` with the correct project URLs. Remove links for projects that do not have a public repository or live demo.
4. Confirm that the listed skills and project descriptions accurately reflect your current work.
5. Deploy the project to Vercel. Use the default Vite build settings: build command `npm run build`, output directory `dist`.

## Tech stack

- React
- Vite
- Tailwind CSS v4
- Lucide React
